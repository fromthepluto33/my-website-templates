# Демонстрационные шаблоны сайтов

Репозиторий содержит демонстрационные шаблоны сайтов, созданные с помощью нейросети.

Проект предназначен для демонстрации возможностей генерации веб-страниц и не является готовым коммерческим продуктом.

## Шаблоны

В репозитории находятся три демонстрационных шаблона:

- Суши-бар — красный вариант
- Суши-бар — золотой вариант
- Кондитерская

Каждый шаблон расположен в отдельной папке и имеет собственную главную страницу `index.html`.

## Онлайн-просмотр

Открыть главную страницу проекта:

```text
https://fromthepluto33.github.io/my-website-templates/
```

Открыть отдельные шаблоны:

| Шаблон | Ссылка |
|---|---|
| Суши-бар — красный вариант | [Открыть](https://fromthepluto33.github.io/my-website-templates/sushi-bar-red/) |
| Суши-бар — золотой вариант | [Открыть](https://fromthepluto33.github.io/my-website-templates/sushi-bar-gold/) |
| Кондитерская | [Открыть](https://fromthepluto33.github.io/my-website-templates/cake-shop/) |

Если вариант с папкой не открывается, можно использовать прямую ссылку на `index.html`:

```text
https://USERNAME.github.io/REPO_NAME/sushi-bar-red/index.html
https://USERNAME.github.io/REPO_NAME/sushi-bar-gold/index.html
https://USERNAME.github.io/REPO_NAME/cake-shop/index.html
```

## Структура проекта

```text
├── index.html          # главная страница со ссылками на шаблоны
├── sushi-bar-red/      # шаблон суши-бара в красной стилистике
├── sushi-bar-gold/     # шаблон суши-бара в золотой стилистике
├── cake-shop/          # шаблон кондитерской
├── README.md           # описание репозитория
└── LICENSE             # лицензия MIT
```

## Технологии

Проект создан с использованием:

- HTML
- CSS
- JavaScript

В шаблонах могут присутствовать дополнительные страницы, например:

- меню;
- доставка;
- контакты;
- о нас.

## Назначение проекта

Репозиторий создан для демонстрации того, какие сайты можно быстро получить с помощью нейросети.

Материалы репозитория можно использовать как:

- примеры оформления;
- макеты для тренировки;
- прототипы страниц;
- основу для дальнейших экспериментов.

## Дисклеймер

Все тексты, изображения и контактные данные в шаблонах являются демонстрационными и не относятся к реальным компаниям, если не указано иное.

Перед использованием шаблонов для реального сайта необходимо заменить демонстрационный контент на актуальный.
